`openspec/changes/add-til-capture-app/design.md`.

Useful things to capture:

- card treatment — corner radius, gradient direction, how much surface lift
- type hierarchy — heading weight against metadata restraint
- spacing and density — how much air between cards
- accent usage — where the one vivid color is allowed to appear
- the widget as it should look on a home screen
